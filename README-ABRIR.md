# Abrir o WorkForge

Abra esta pasta no VS Code e execute no PowerShell:

```powershell
corepack pnpm@11.13.0 install --force
corepack pnpm@11.13.0 run dev
```

Depois acesse:

```text
http://127.0.0.1:4173/login
```

O terminal precisa permanecer aberto enquanto o sistema estiver rodando.

No primeiro acesso, conclua o onboarding ou use a opção **Usar sistema básico**.
Depois, utilize **Ver portal do cliente** para alternar entre a operação da agência e a experiência externa.
